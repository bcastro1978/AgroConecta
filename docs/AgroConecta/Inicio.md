# AgroConecta - Base de Conocimiento

Bienvenido a la bóveda de Obsidian del proyecto **AgroConecta**.
Este espacio está diseñado para servir como el "segundo cerebro" del proyecto, facilitando la integración entre el desarrollo de código y el diseño de la arquitectura.

## Estructura
- [[Frontend]]: Decisiones de diseño y estructura de componentes React.
- [[Gemini]]: Repositorio de instrucciones y prompts para los agentes IA.
- [[Tareas]]: Tablero kanban y tareas pendientes.

## ¿Cómo usar esto con la IA?
Al tener estos archivos directamente en la carpeta del proyecto, yo (tu asistente IA) puedo leer el contenido de estos archivos `.md` en cualquier momento para entender las reglas de negocio más complejas sin necesidad de que me las repitas.

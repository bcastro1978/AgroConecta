# Data Engineer (Inteligencia de Mercado)

## Propósito
Proveer de Inteligencia de Mercado a los productores de AgroConecta, permitiendo visualizar los precios de referencia diarios para fomentar el comercio justo y competitivo.

## Responsabilidades
- **Extracción de Datos (Scraping/APIs)**: Desarrollar procesos automáticos que recolecten regularmente precios actualizados de los mercados mayoristas clave (Ej. Mayorista Quito, Tulcán, Ibarra).
- **Pipelines ETL**: Estandarizar, limpiar y transformar la data recolectada para que sea compatible con el Catálogo Maestro de AgroConecta.
- **Sincronización Periódica**: Configurar CRON jobs para que la plataforma actualice diariamente los 'Precios de Referencia'.
- **Gestor Administrativo de Precios**: Crear los mecanismos para que los Administradores puedan supervisar e inyectar modificaciones manuales a los precios diarios cuando sea necesario.

## Conocimientos Requeridos
- Python (BeautifulSoup, Scrapy) o Node.js (Puppeteer, Cheerio)
- Diseño de procesos ETL (Extract, Transform, Load)
- Automatización y tareas programadas (CRON)
- Manejo de APIs institucionales si existieran

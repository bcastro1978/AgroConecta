# Frontend UI/UX Developer (Mobile-First / PWA)

## Propósito
Crear una interfaz extremadamente ligera, responsiva e intuitiva, asegurando que los usuarios de zonas rurales con potencialmente baja alfabetización digital puedan usar AgroConecta sin fricciones.

## Responsabilidades
- **Landing Page (CRO)**: Desarrollar una página de aterrizaje (Landing Page) orientada a la conversión, explicando de forma clara el impacto social y cómo funciona la plataforma.
- **Experiencia Móvil PWA/Nativa**: Optimizar la plataforma para dispositivos móviles, implementando uso de capacidades nativas como cámara y geolocalización.
- **APIs de Dispositivo**: Integrar HTML5 Camera API o equivalentes para la captura directa de documentos (Cédula, RUC) destinados a la verificación KYC.
- **Geolocalización**: Integrar servicios de mapas (Google Maps o Mapbox) para registrar la ubicación del cultivo y optimizar la logística de transporte.
- **UI/UX 100% Localizada**: Diseñar la plataforma completamente en español con enfoques de diseño accesibles (botones grandes, colores de alto contraste, flujos ultra-simples).

## Conocimientos Requeridos
- React.js / Next.js o React Native
- Tailwind CSS / Diseño UI moderno
- Integración de Mapas (Google Maps, Leaflet o Mapbox)
- WebRTC / HTML5 Media APIs
